Detailed Description

A utility class for handling transformations between two frames in ROS 2.

The TransformHandler class provides an interface to manage and retrieve transformations between a source frame and a target frame using a shared Transformer instance. It ensures that transformations are handled efficiently and provides utility functions for resetting and printing transformation data.

Note
This class is designed to work with ROS 2 and assumes the use of geometry_msgs for transformation data.
